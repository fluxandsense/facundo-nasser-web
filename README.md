# Facundo Nasser — Saxofonista

Sitio estático de una página para Facundo Nasser (saxofonista): jazz, cumbia, tango,
rock y temas propios. Contacto por WhatsApp.

## Estructura

```
index.html      # todo el sitio (CSS y JS embebidos)
img/            # foto optimizada en jpg + webp (560/1000/1900 px)
previews/       # capturas de referencia (escritorio / móvil)
```

## Editar

- Textos y secciones: `index.html` (bloques comentados por número 01–04).
- Paleta y tipografía: variables CSS en `:root` al inicio del `<style>`.
- Foto: reemplazar los archivos de `img/` manteniendo los nombres.
- WhatsApp: buscar `5491159915500`.
- Instagram: buscar `instagram.com/todoesrecursivo`.

## Ver en local

```bash
python3 -m http.server 8799
```

Abrir http://127.0.0.1:8799
